# StellarDaybook

A modern web application for scheduling, booking management, and daily tracking.

## Features

- 📅 Interactive calendar view for booking and event management.
- 🔐 User authentication and authorization control.
- 📊 Dashboard with activity analytics.
- 📱 Responsive design built for desktop and mobile devices.

## Tech Stack

- React / TypeScript
- Tailwind CSS
- Node.js / Express
- PostgreSQL

## Installation & Setup

```bash
# Clone the repository
git clone https://github.com/JackStar6677-1/StellarDaybook.git

# Install dependencies
npm install

# Start development server
npm run dev
```
